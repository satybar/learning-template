### Structure of the template page
A great, clean structure for tracking technical learning topics usually includes the following files. You can create these directly on GitHub or push them from your computer:
##### README.md: 
The homepage of your repo. Use it to outline your learning goals, resources, and progress.
##### notes/: 
A folder dedicated to your markdown study notes, commands, and cheat sheets.
##### labs/: 
A folder to hold your actual scripts, code snippets, or configuration files (like PowerShell scripts or SQL queries).
##### .gitignore: 
A file to prevent accidental uploads of temporary files or system clutter
##### .LICENSE: 
Optional, but good if you make the repo public and want to share your code.
